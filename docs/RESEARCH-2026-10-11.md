# Research findings - 2026-10-11 (next build-out)

Investigation (3 parallel agents) for: buff/consumable impact, racial impact, and the
baked-in synergy UI + auto-update data system. All grounded in verified DB2 (served for
build 1.60.1.70338), real Forever APIs (forever-addon-kit baseline + live harvest), and
our existing architecture. Source of record for the stories in SPRINTS.md.

## Common thread: everything reuses `build_ops()` + `applyOps()`
A buff, a racial, and a talent are mechanically identical: a spell whose SpellEffect rows
carry stat/school/crit/threat auras. `pipeline/generate.py:build_ops()` already decodes
them; `Foresight/model/loadout.lua:applyOps()` already folds the ops into the graph. New
features add a front-link (item->spell, race->spell) then reuse both verbatim. No forked
value math (triage law).

## A. Buffs & consumables (alchemy/food/scrolls) - "active vs expired"
- **Live read (secret-safe):** `C_UnitAuras.GetPlayerAuraBySpellID(spellId)` (cleanest own-
  aura read) or `AuraUtil.ForEachAura("player","HELPFUL",nil,cb,true)`. AuraData is secret
  in restricted contexts BUT **spellId is NeverSecret** -> the generated spellId->ops table
  is the ONLY secret-safe way to know a buff's effect. Gate with `C_Secrets.ShouldAurasBeSecret`
  (extend guards.lua, which today only checks ShouldUnitHealthMaxBeSecret).
- **DB2 chain (all served, verified):** `ItemXItemEffect(ItemID->ItemEffectID)` -> `ItemEffect(.SpellID)`
  -> SpellEffect (reuse build_ops). `ItemSparse`/`Item`(ClassID=0 Consumable, SubclassID splits
  potion/elixir/flask/food/scroll), `SpellAuraOptions.CumulativeAura`(max stacks),
  `SpellDuration.Duration`(ms). Add these to fetch.py.
- **Validated:** Elixir of the Mongoose(13452)->spell 17538 = +25 Agi(aura29) +2% crit(aura290),
  30min. Flask of Supreme Power->17628 = +150 spell dmg(aura13). Scroll of Agility IV->12174 = +17 Agi.
- **New decode work (only this):** aura 290 -> `property="crit chance"` (one AURA map entry);
  and chase `EffectTriggerSpell` one hop for food/Well-Fed (the stat buff is a triggered aura).
- **Model:** `Loadout:withBuff(id)` (mirror withTraitNode) -> applyOps; `Impact.buffDelta` =
  one `diff()` gives "while active +X%" and "on expiry -X%". `Snapshot.captureActiveBuffs()`.
- **Emit** `data/generated/consumables.lua` (scoped to consumables, not all items - bloat).
  Tag `classic-presumed`. Prioritize survival consumables (Stamina/armor/HP) for the hardcore thesis.

## B. Racials - permanent effects like talents (NOT in the trait trees)
- **Confirmed:** racial spell IDs are NOT in TraitDefinition/traits.lua -> separate path.
- **DB2 chain (served, verified):** `SkillLineAbility.RaceMasks_0/1` (bit = `1<<(ChrRaces.ID-1)`)
  on a CategoryID-9 "Racial" SkillLine -> `.Spell` -> SpellEffect (reuse build_ops). `ClassMask`
  gates class-specific racials. Tables: ChrRaces, SkillRaceClassInfo (+ SkillLine/SkillLineAbility
  already fetched). Key data by **raceID** (UnitRace return #3), not token.
- **Gotchas:** Undead token = `"Scourge"` (not "Undead"); hardcode token->raceId map.
  NEW RACE "Skyborne" (ChrRaces 95/96, SkillLine 2980) uses RaceMasks_1 small bits that break
  the `1<<(id-33)` formula - handle explicitly or fall back to live spellbook enum.
- **Forever reworked racials** (~2 active + 2 passive/race); classic IDs coexist with new 1.25M+
  IDs on the same racial SkillLines (e.g. Gnome Expansive Mind 1259802, Human Will to Survive
  1259718). Tag classic IDs `classic-presumed`, new IDs `forever-new-unverified`.
- **New aura decodes worth adding:** 178 (max-mana%), 166/167/317 (Blood Fury AP/SP%), others
  land in needsCuration like the 182 proc talents. Active racials surface via tooltip only.
- **Model:** capture `snapshot.raceId`; in `loadout:build()` fold passive racial ops as PERMANENT
  modifiers via applyOps (`"racial:"..spellID`). Optional `withRace()` what-if. Feed Synergy +
  a panel "Your <Race> racials give you:" line. Curation -> `overrides.racialImpacts`.

## Phase 1 - Racials (self-contained; smaller; do first) - SHIPPED v0.11.0
Implementation corrections (2026-10-11, same day):
- The RaceMasks bit index is `ChrRaces.PlayableRaceBit` (Human=0..Troll=7; Skyborne
  95/96 carry bits 32/33 -> RaceMasks_1 bits 0/1). The 1<<(ID-1) formula was only
  coincidentally right for races 1-8; with PlayableRaceBit the decode is fully
  data-driven and the planned Skyborne hardcode (step 2a) was unnecessary.
- Step 4 correction - NO unconditional permanent fold: live snapshot stats ALREADY
  include racial passives (UnitStat/UnitHealthMax/GetDodgeChance...), so folding them
  into every build() would double-count (same marginal-only law loadout.lua applies to
  AP/crit). Racials model as what-if deltas (`withRacial`/`withRace`) and surface via
  synergy/panel (phase 3). Weapon-spec crit (aura 290) is CONDITIONAL on racials
  ("while you have an axe equipped") - kept label-only; the phase-2 fold decision needs
  an equipped-item discriminator (SpellEquippedItems) for consumable vs racial 290s.
- Extra ground-truthed decodes shipped: aura 133 max-health% (Endurance) and 178
  max-power% (misc0 = power type) fold; 49/54/55/166/167/317/290 are label-only.
1. `pipeline/fetch.py`: add `ChrRaces`, `SkillRaceClassInfo` to TABLES (SkillLine/SkillLineAbility/
   SpellEffect already fetched). Verify served for build 1.60.1.70338.
2. `pipeline/generate.py`: new racials pass -
   a. Decode `SkillLineAbility.RaceMasks_0/1` (bit = `1<<(ChrRaces.ID-1)`, IDs 1-32 in _0, 33-64 in
      _1) on CategoryID-9 racial SkillLines -> race -> racial spellIDs. HARD-CODE the Skyborne
      edge (ChrRaces 95/96, SkillLine 2980, faction bits in _1 that break the formula).
   b. Add racial spells to `player_spells` (so spellmod affected-lists resolve) and `ship_spells`.
   c. Run existing `build_ops()` on each racial spell. Emit `data/generated/race_racials.lua`:
      `HM.gen.racials = { [raceID] = { token, name, spells = { {spellID,name,classMask,ops,needsCuration?} } } }`
      + a `tokenToRaceId` map (HARD-CODE Scourge->5). Add racialSpells counts to build.lua.
   d. Add to `.toc` after `traits.lua`.
3. Decoder additions (reduce needsCuration for common racials): aura 178 (max-mana %), aura
   166/167/317 (Blood Fury AP/SP %). Confidence: classic IDs `classic-presumed`, 1.25M+ IDs
   `forever-new-unverified`.
4. Model: `snapshot.lua` capture `raceId` (UnitRace #3, guarded); `loadout.lua:build()` fold the
   player's PASSIVE racial ops as permanent modifiers via `applyOps(g, ops, 1, 1, "racial:"..id)`
   (class-gated by classMask). Optional `Loadout:withRace(raceId)` what-if.
5. Selftest: a known racial decodes (e.g. The Human Spirit -> +5% Spirit), racials fold into
   dimensions, Scourge->5 maps. Gate, deploy, commit, doc-sync.

## Phase 2 - Buffs & consumables
1. `pipeline/fetch.py`: add `ItemEffect`, `ItemXItemEffect`, `ItemSparse`, `Item`, `SpellAuraOptions`.
2. `pipeline/generate.py`: consumables pass -
   a. `Item.ClassID==0` (Consumable); join `ItemXItemEffect(ItemID->ItemEffectID)` -> `ItemEffect.SpellID`.
   b. Run `build_ops()` on the buff spell; if no stat aura on the direct spell, chase
      `EffectTriggerSpell` ONE hop (food/Well-Fed). Keep only items whose buff has stat/damage/crit ops.
   c. Emit `data/generated/consumables.lua`: `HM.gen.consumables = { [itemId] = { buffSpellId, name,
      type(from Item.SubclassID), durationMs(SpellMisc.DurationIndex->SpellDuration.Duration),
      maxStacks(SpellAuraOptions.CumulativeAura), reqLevel, ops } }` + `buffsBySpell` index. Scope to
      consumables only (not all items - bloat). `.toc` after race_racials.lua.
3. Decoder addition: aura 290 -> `kind="spellmod", property="crit chance"` (applyOps already folds it).
4. Model: `Loadout:withBuff(itemIdOrSpellId)` (mirror withTraitNode) + `d.type=="buff"` in build();
   `Impact.buffDelta(loadout, id)` = one `diff()` -> "while active +X% / on expiry -X%".
5. Live (secret-safe): `Snapshot.captureActiveBuffs()` via `C_UnitAuras.GetPlayerAuraBySpellID` /
   `AuraUtil.ForEachAura("player","HELPFUL",nil,cb,true)`; match spellId (never-secret) to buffsBySpell;
   extend `guards.lua` with `C_Secrets.ShouldAurasBeSecret` degrade. Item tooltip provider: "While
   active: +X% for you; expires in Zm". Selftest (Elixir of the Mongoose -> +25 Agi +2% crit; withBuff
   raises survivability; expiry reverses). Gate, deploy, commit, doc-sync.

## Phase 3 - Synergy draws from all sources

2. So `/foresight synergy intellect` and the tooltip "Synergy:" line include racial + consumable

3. (Separate, UI not pipeline) SYNERGY-highlight: `ui/synergy_highlight.lua` - LibCustomGlow PixelGlow
